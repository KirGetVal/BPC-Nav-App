Campuses are confusing when you are new.

Commercial maps rarely show the labs, restrooms and offices of a local college, and many need paid API keys or a steady connection.

Room scheduling is just as messy. Without one place to request and approve bookings, teachers and students end up double-booking the same room.

BPC Campus Navigator puts the directory, the routes and the approval queue in one free app.

What you can do with it

Pick a feature to see how it works.

Made for everyone on campus

Students and enrollees

Find lecture rooms, ComLab 1, science labs, the NTT lab, printing and restrooms. Request a room for a study group or event.

Faculty and teachers

Locate academic offices and the medical clinic. Book a room for a makeup class or department meeting.

Campus administrators

Approve or reject pending requests, browse the user directory and watch room utilization from one dashboard.

Visitors and guests

Spot the arch gate, canteen, activity center, stage and food stalls without asking around.

Install it in four steps

The app is shared as an APK file, so Android will ask you to allow the install once.

  1. 1

    Download the APK

    Tap Download for Android. Keep the file in your Downloads folder.

  2. 2

    Open the file

    Tap the downloaded file from your browser or a file manager.

  3. 3

    Allow the install

    If Android blocks it, open Settings when prompted and allow installs from this browser, then go back and tap Install.

  4. 4

    Open and allow location

    Grant location access so the map can center on you and plan routes from where you stand.
